# moeun

목표 기반 개인 자산관리 AI Agent (3주 해커톤 MVP)

| 폴더 | 내용 |
|---|---|
| `frontend/` | React |
| `backend/` | Spring Boot: 계산 엔진, 계획 저장·적용, 인증, 대화 저장 |
| `ai-server/` | FastAPI: AI 설명, 대화, RAG |
| `db/` | DB 설계 결정과 테이블 설명 |
