페르소나마다 아래 5가지를 확인한다.

| 테스트 | 프로젝트 목표 | 확인하는 성질 |
|---|---|---|
| `test_s6_1` | 3. 목표 달성 시뮬레이션 | 원금 = 보유 + 월저축 x 기간, 자산 = 원금 + 세후 수익, 부족·초과 = 자산 - 목표, 달성 = 자산 ≥ 목표, 좋았던 때 ≥ 평균 ≥ 나빴던 때, 그래프 점(기간+1개, 첫 점 보유, 끝 점 결과), 화면 문자열 = 숫자, 이론상 판정, 저장 시간 < 3초 |
| `test_s6_2` | 핵심특징 4. 정확한 계산 | 적금 100%로 바꾸면 결과 하나, 명세 공식 손계산과 원 단위 일치(금리 0%면 자산 = 원금) |
| `test_s6_3` | 2. 자산별 위험 구분 | ETF 0 → 30 → 50 → 70 → 100%로 갈수록 좋았던 때~나빴던 때 폭이 넓어짐, ETF 0%면 폭 0 |
| `test_s6_4` | 4. 전략 비교 | 월 저축 +10만 → 모든 구간 자산 증가(원금 차이 = 10만 x 기간), 금리 +1%p → 자산 증가, 목표만 바꾸면 자산 그대로·판정만 바뀜 |
| `test_s6_5` | 4. 전략 비교 | 기준 판정이 미달일 때만 대안이 나오고, 월 저축·기한 대안은 평균 결과를 실제로 개선 |

실행이 끝나면 `report.md`에 페르소나별 결과 표(판정, 3구간, 적금만 계산 일치 여부, 대안 유무, ETF 비중별 폭, 저장 시간)가 생긴다.
여기서 숫자가 "말이 되는지" 눈으로 한 번 더 본다.

## S7. 페르소나 x 말투 (`test_11_persona_chat.py`, `-m ai`)

P02·P03·P15 계획에서 6가지 질문(월 저축 절대값, "매달 백만 원씩", "N년으로", "적금 70 ETF 30", "금리 4.5%", "목표 N만원으로 낮추면")을 던진다.
질문마다 RECALC_RESULT인지, 도구가 **그 조건 하나를 그 값으로** 불렀는지(F-4 `changedKeys`·`conditions`), 문장 속 금액이 모두 계산 결과에 있는지 본다.
또 P02·P03·P05·P09·P15 설명이 계산 판정과 반대로 말하지 않는지(미달인데 부족 언급 없음 등) 본다.
